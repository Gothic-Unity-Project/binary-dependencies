# Gothic-Unity-binary-dependencies

Binaries for [Gothic Unity](https://github.com/Gothic-Unity-Project/Gothic-Unity), loaded as a Unity package
instead of being stored in Git LFS.

## Licensing

The root `LICENSE` (GPL-3.0) covers this repository's own content (package setup, scenes, documentation).
The third-party binaries in `Core/Dependencies/<Component>/` keep their **own** licenses, and each component
folder has its license file(s) next to the binaries. See `Core/Dependencies/README.md` for an overview.
